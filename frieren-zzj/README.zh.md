# @zengzhaojun/dsh-client-frieren-zzj

dsh-芙莉莲-zzj —— 芙莉莲 × 辛美尔（葬送のフリーレン）装饰主题：别名令牌覆盖层、全局样式表与装饰插槽条目。浏览器半部通过主题服务叠加令牌层、注入全局样式表（奇幻衬线标题、金紫渐变滚动条、星光、苍月草飘花、魔法阵），并向各插槽注册帧级装饰层、勇者金戒指印章、会话头部徽记与轮换的辛美尔铭文（点击台词可换下一句）。初始状态为无壁纸，用户可自行上传图片作为整体背景，并调节模糊度与暗度。

## 配置

插件拥有独立的「芙莉莲主题」设置分区（`settings.section`，位于设置导航中 General 之后），行均持久化到 `frieren-zzj` 命名空间：

- **插件总开关**（默认为开）：关闭后令牌层、主题字体、壁纸、装饰舞台、玻璃材质、金戒指、徽记、台词**全部移除**，界面恢复默认外观；分区只保留总开关与恢复按钮，方便随时开回来；
- 外观模式（浅色 / 深色 / 跟随系统 —— 复用主题服务自己的 `ui-theme` 偏好命名空间，与内置「外观」行同步）；
- 自定义壁纸上传（压缩为 JPEG data URL 存入设置文档，再次上传即替换，「移除壁纸」一键清除）。初始状态为**无壁纸**，用户上传后壁纸作为整体背景以独立固定层渲染（`position:fixed; z-index:-2`，配合 `transform:scale(1.1)` 与 `transition:filter 0.3s ease`），不干扰 `body` 默认布局；
- **壁纸画廊与轮播**：上传的图片累积进画廊（上限 6 张，可逐张移除或一键清空），整体存为一个 JSON 数组字段。旧的单图 `customWallpaper` 字段继续可用——解析器会把它折进画廊，直到第一次编辑将其清空。有 2 张以上图片时出现轮播行：间隔（5 秒–10 分钟）与顺序（顺序 / 随机；随机模式每次必定换到与当前不同的一张）。仅一张图片时不启动定时器，行为与旧版完全一致；
- **壁纸文件存储**（node 半边）：`POST <壁纸前缀>` 解码 jpeg/png/webp data URL，按内容哈希写入 `dshHomePath('plugin-data', 'frieren-zzj', 'wallpapers')`，返回 `<前缀>/<sha256-32>.jpg`；`GET`/`HEAD` 以 immutable 缓存头回传。浏览器半边把它当作**可选优化**：任何失败（旧 node 半边、磁盘错误、文件缺失）都退回把图片内联为 data URL，与旧版一致。**移除单张 / 清空画廊 / 导入备份**都会对因此成为孤儿的文件发出显式 `DELETE`——因为文件名是内容哈希，被两个条目共用的文件只在最后一个引用消失时才删除；每次激活还会再扫一遍兜底，并保留 5 分钟内写入的（只用于保护"文件已写、设置还没落盘"的在途上传）。**上传前先校验容量**：画廊满额时直接拒绝，不写入任何文件。已知限制：导出的备份里是存储 URL 而非图片本体，所以把备份换到另一台机器（或删掉 `plugin-data` 后再导入）需要重新上传图片；
- **壁纸模糊度**（0px–20px）：滑块实时调节壁纸背景的 CSS `filter: blur()`，配合 4 个预设按钮（无模糊 / 轻度 / 中度 / 重度），变化时平滑过渡（`transition: filter 0.3s ease`）。`transform: scale(1.1)` 防止模糊后边缘漏出。仅在设置了壁纸时显示；
- **壁纸暗度**（0%–80%）：滑块在壁纸图像上叠加黑色遮罩，让花哨背景上的文字依然清晰，配合 4 个预设按钮（无 / 轻度 / 中度 / 重度）。0% 时只输出图片 URL，与未启用该功能时的渲染完全一致。仅在设置了壁纸时显示；
- 整体材质（玻璃 / 普通）：`glass` 给输入框卡片（`[data-composer-card]`）、任务清单卡片（`[data-testid='todo-panel']`）、目标卡片（`[data-goal-bar] > :first-child`）与设置面板（`[role="dialog"][aria-modal="true"]`）应用**固定配方**的毛玻璃——参考 OceanAvenu Dark Glass 方法（https://blog.csdn.net/qq_43433246/article/details/162127888）：极低透明度的玻璃底、强模糊（浅色 28px / 深色 40px）、低透明度白边、轻方向悬浮投影、大圆角；浅色与深色两套配方内建、**不可调节**。`plain` 移除样式，所有卡片回到默认表面。消息区卡片（气泡、工具卡）刻意不玻璃化，消息区保持透明，壁纸完整可见。深色规则挂在 `body[data-ds-dark-theme]` 上，跟随用户手动选择的深浅色（而非系统媒体查询）；
- 逐层装饰开关（星光、飘花、魔法阵、彩带、暗角）；
- 装饰微调：数量（0.25×–2×，按等距抽稀保留元素，使其仍均匀铺满画面而非挤在一侧）、速度（0.25×–4×，统一缩放星光与飘花的动画时长）、魔法阵大小（0.5×–2×，围绕自身中心缩放），并附「恢复默认」按钮；
- 施法指示器（`conversation.input.overlay`）：模型生成中时，输入框上方浮现一枚缓慢旋转的迷你魔法阵与「詠唱中…」；空闲时不渲染，因此不占布局。该条目为 session 级，通过运行时提供的 `useSession` 标准属性读取忙碌状态；
- 专注模式：一个开关（以及被点击时的侧边栏金戒指，二者写入同一字段）隐藏会动的装饰——星光、飘花、魔法阵、彩带、暗角，同时保留壁纸、配色、主题字体、金戒指、徽记与名台词。专注模式开启时，金戒指变暗并去饱和；
- 性能档位（全效 / 标准 / 省电）：一键同时写入数量、速度与材质（省电档切到 `plain`，避开昂贵的 `backdrop-filter`）；手动调过任意一项后该行显示「自定义」；
- 深色星空层：固定在内容之后、壁纸之上的一层缓慢漂移星空（`z-index: -1`），仅在 `body[data-ds-dark-theme]` 下点亮；专注模式会随其它装饰一并收起，减少动态效果下漂移静止；
- 备份与分享：把整套配置导出为 JSON 文档，或导入一份。导入会逐字段校验、把识别出的字段**合并**到当前设置（缺少某字段的旧文件、或不含壁纸的文件都不会把它清空），并回报被跳过的键；
- 名台词轮换方式（随机 / 固定），内置 8 句台词库；两种模式下**点击台词即可换下一句**（仅当前会话有效，不写入设置）；
- **恢复默认设置**（分区底部按钮）：整段重置为默认值（无壁纸、玻璃材质、装饰全开、随机台词、模糊度恢复 0px、清除自定义壁纸）并重新开启插件。

所有行通过 revision 缓存的 observable 读取；设置文档缺失时各字段回退到默认值。

## 减少动态效果

遵循系统的 `prefers-reduced-motion: reduce`：装饰动画停止，但装饰本身保留在画面上——星光停在其点亮透明度、飘花停在视口内（而非冻结在顶边之外或半空中）、魔法阵保持形态、壁纸层的模糊/暗度过渡被移除。该行为由操作系统设置驱动，插件不提供对应开关。

## Model Experience

None, as this package affects no model context: it only overrides theme
tokens, injects a static stylesheet, and registers decorative slot entries.

#### KV Cache effect

Does not invalidate: the package neither reads nor writes model requests, so
it never changes the prompt or message prefix; provider cache availability and
eviction remain outside the package contract.

## 已知限制与后续工作

- 自定义壁纸以 JPEG data URL 存入用户设置文档（上传时自动压缩到最长边 1920px）。
- 名台词为粉丝整理的日文原句 + 意译，非官方翻译。
- 标题字体在运行时从 Google Fonts 加载；离线时会回退到本地衬线字体栈。
